1 - O que é uma classe?

Uma classe é como um molde usado para criar objetos. Ela define quais propriedades e métodos esses objetos podem ter.

2 - O que é um objeto?

Um objeto é uma instância de uma classe. Ele possui estado, representado pelas propriedades, comportamentos representados pelos métodos.

3 - O que é assinatura de um método?

A assinatura de um método identifica o método através do seu nome e dos seus parâmetros.

4 - Descreva a assinatura de um método

A assinatura de um método é composta pelo nome do método e pela lista de parametros.

5 - Descreva o retorno de um método

O retorno é o valor que um método devolve depois de ser executado. O tipo de retorno diz qual tipo de valor o método pode devolver.

6 - Defina o que é escopo

Escopo é a região do codigo onde uma variável, método ou outro elemento pode ser acessado.

7 - Defina variável global

Uma variável global pertence a um objeto e pode ser acessada por outros objetos.

8 - Defina variável local

Uma variável local é uma variável declarada dentro de um método ou bloco de código. Ela só pode ser acessada dentro daquele escopo.

9 - O que é um construtor?

Um construtor é um método especial usado para inicializar um objeto quando ele é criado. Ele tem o mesmo nome da classe e não possui tipo de retorno.

10 - O que é herança?

Herança é quando uma classe estende outra classe, podendo reutilizar seus atributos e métodos e também adicionar novos comportamentos.

11 - O que é uma interface?

Uma interface é um contrato que define comportamentos que uma classe deve implementar. 

12 - O que é uma classe abstrata?

Uma classe abstrata é uma classe que não pode ser instanciada diretamente. Ela serve como base para outras classes e pode possuir tanto métodos implementados quanto métodos abstratos.

13 - O que é encapsulamento?

Encapsulamento é uma forma de proteger o estado interno de um objeto, controlando como seus dados podem ser acessados e expondo apenas o necessário.
